How To Use Course Mapper

Create course files for EzyGolfer, Scrambler, MatchPlay Golf & Stableford Golf.

1 — Name Your Course

Type your course name in the field at the top left. Use the exact name you want to appear in the app.

2 — Navigate to Your Course

Tap My Location to jump the map to where you are (works on-course from a phone). Or pan and zoom the satellite map manually to find your course. Use zoom levels 17–18 to see individual holes clearly.

3 — Map Each Hole

Use the hole numbers (1–18) at the top of the right panel to move between holes. For each hole:

  • Drag the blue TEE marker to the tee box on the satellite image
  • Drag the yellow GREEN (C) marker to the centre of the green
  • Tap Set F then tap the front edge of the green — places the green Front marker; drag to adjust
  • Tap Set B then tap the back edge of the green — places the green Back marker; drag to adjust
  • Set the Par (3, 4, or 5) and Stroke Index (1–18) from your scorecard
  • Tap Orient to rotate the view so tee is at the bottom and green at the top — makes placement easier
  • Distance and bearing calculate automatically as you drag
4 — Add Hazards (Optional)

Tap Bunker, Water, Trees, or OB to activate that hazard type, then tap the map to place a marker. Drag markers to adjust. Tap the hazard button again to deactivate.

5 — Mark Driver Landing (Optional)

Tap Set DL then tap the map where a good drive lands on this hole. The orange DL marker is draggable once placed. The GPS screen in EzyGolfer will show your live distance to this point so you know exactly how far you need to carry.

6 — Save As You Go

Tap Save regularly — your work is stored in the browser. Holes with both TEE and GREEN placed show a blue border in the hole number grid.

7 — Export & Import Into the App

When all 18 holes are done, tap Export → Download JSON File. This saves a .json file to your device.

To load it into the app: Settings → Import Course Mapper and select the file.

Compatible with: EzyGolfer · Scrambler · MatchPlay Golf · Stableford Golf

8 — Add Tees, Distances & Ratings

In the right panel, tap Manage Tees & Distances to define multiple tees (White, Blue, Red etc.) with Course Rating and Slope Rating, then enter the yardage for each hole per tee. Use Fill GPS to pre-fill a tee's distances from your marker positions as a starting point.

Tee data is included in the exported JSON and imported automatically into the app — each tee appears as a selectable option when starting a match.

Map Tile Options

Two satellite map sources are available — toggle between them using the ArcGIS / Google buttons in the header.

ArcGIS (free, no sign-up)

High-res satellite imagery with no account or API key required. Works immediately out of the box. Quality varies by location.

Google Maps Satellite (sharper, free API key required)

The same imagery you see in Google Maps/Earth — noticeably sharper for golf courses. Requires a Google Maps API key:

  1. Go to console.cloud.google.com and sign in with your Google account
  2. Create a new project (or use an existing one)
  3. Go to APIs & Services → Library and enable Maps JavaScript API
  4. Go to APIs & Services → Credentials → Create Credentials → API Key
  5. Copy the key and paste it when prompted after clicking the Google button in Course Mapper

Free tier gives $200/month credit. Maps JavaScript API costs $7 per 1,000 loads. At that rate you'd need to open this page ~28,000 times a month to see a bill — it's effectively free for personal use. A credit card is required to create the account but will not be charged at personal-use volumes.

Tips
  • Best done on-course with the phone — use My Location to stay oriented
  • You can do it from a desktop using Google Maps or the course website to identify hole positions
  • Par and Stroke Index come straight from your paper scorecard
  • Use Import to reload a previously saved file and continue editing
  • Tap Clear to reset a single hole if you need to start it over
